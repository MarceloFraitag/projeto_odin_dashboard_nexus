## English

Admin Dashboard developed as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

The project focuses on building a multi-section dashboard using CSS Grid, nested layouts, Flexbox, and reusable styling. The interface follows the original design provided by The Odin Project.

### Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, Custom Properties, Media Queries)
- Google Fonts (Roboto)
- Material Design Icons (MDI)

### Features

- **CSS Grid Layout:** Main structure divided into sidebar, header, and content areas using named grid areas.
- **Nested Grids:** Additional grid layouts for the header, project cards, and content organization.
- **Navigation Sidebar:** Vertical navigation menu with Material Design icons.
- **Dashboard Header:** Search field, notification icon, user profile, and action buttons.
- **Project Cards:** Six project cards organized in a two-column layout, with accent borders and action icons.
- **Announcements and Trending:** Dedicated panels for community updates and user profiles.
- **Responsive Adjustments:** Layout adaptations for smaller screens.

### How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/MarceloFraitag/projeto_odin_dashboard_nexus.git
   ```

2. Open the project directory.

3. Open `index.html` in your browser or use the Live Server extension in VS Code.

An internet connection is required to load external fonts, icons, and avatar images.

### Project Scope

This is a front-end layout exercise. Search, navigation links, and action buttons are visual elements and do not implement application functionality.

## Português

Admin Dashboard desenvolvido como parte do currículo do [The Odin Project](https://www.theodinproject.com/).

O projeto tem como objetivo praticar a construção de interfaces com CSS Grid, layouts aninhados, Flexbox e estilos reutilizáveis. A interface segue o modelo visual disponibilizado pelo The Odin Project.

### Tecnologias Utilizadas

- HTML5
- CSS3 (Grid, Flexbox, Variáveis CSS, Media Queries)
- Google Fonts (Roboto)
- Material Design Icons (MDI)

### Funcionalidades

- **Layout com CSS Grid:** Estrutura principal dividida em barra lateral, cabeçalho e conteúdo utilizando áreas nomeadas.
- **Grids Aninhados:** Organização do cabeçalho, cartões e seções internas com diferentes configurações de Grid.
- **Menu Lateral:** Navegação vertical com ícones Material Design.
- **Cabeçalho:** Campo de pesquisa, notificações, perfil do usuário e botões de ação.
- **Cartões de Projetos:** Seis cartões organizados em duas colunas, com bordas de destaque e ícones.
- **Anúncios e Tendências:** Painéis dedicados a comunicados e perfis de usuários.
- **Ajustes Responsivos:** Adaptação do layout para telas menores.

### Como Executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/MarceloFraitag/projeto_odin_dashboard_nexus.git
   ```

2. Abra a pasta do projeto.

3. Abra `index.html` no navegador ou utilize a extensão Live Server do VS Code.

É necessária conexão com a internet para carregar fontes, ícones e imagens externas.

### Escopo do Projeto

Este é um exercício de desenvolvimento front-end focado em HTML e CSS. A pesquisa, os links de navegação e os botões são elementos visuais, sem funcionalidades implementadas.
